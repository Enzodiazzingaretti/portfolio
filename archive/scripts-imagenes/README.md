# Scripts de imágenes (archivados)

Tooling puntual que se usó **una vez** para convertir y limpiar los assets del sitio
durante el desarrollo. Ya cumplieron su función (las imágenes están convertidas) y se
movieron acá para desordenar menos la raíz. No los referencia el build ni el código.

- `convert-images.ps1` / `convert-images.sh` / `convert-images-ffmpeg.sh` / `convert-simple.ps1` — variantes de conversión de imágenes.
- `copy-images.ps1` — copia de assets.
- `clean_assets.py` / `cleanup_assets.py` — limpieza de assets.
- `fix-permissions.ps1` — arreglo de permisos.

Archivados el 2026-07-24.
